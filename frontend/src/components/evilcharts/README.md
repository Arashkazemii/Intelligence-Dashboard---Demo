The chart components in `charts/` and `ui/` were copied from the EvilCharts Recharts registry (`https://evilcharts.com/r/`) for this ViraData demo. EvilCharts is MIT licensed; its copyright and license notice are preserved in [LICENSE](LICENSE). Upstream license: `https://github.com/legions-developer/evilcharts/blob/main/LICENSE`.

The ViraData wrappers in `src/charts.tsx` provide the data mapping, Persian labels, colors, units, accessible selection controls, and chart sizing. The shared tooltip was adapted to format billion-toman values in Persian digits.

`src/dashboard-charts.tsx` renders the version 2 validated `ChartSpec` registry. Area, composed, radial, and radar sources were copied directly from their official registry JSON on 2026-10-19: `https://evilcharts.com/r/recharts-{area,composed,radial,radar}-chart.json`. Their imports were adapted to this directory. Their registry dependencies are the existing shared EvilCharts chart, tooltip, legend, dot, brush, and background components. Their package dependencies are the project's existing Recharts and Motion packages; no new package was introduced.

The dynamic registry supports area, line, vertical bar, horizontal bar, grouped bar, additive stacked bar, composed bar and line, pie, donut, radial, normalized radar, and waterfall. Line, area, bar, and composed charts use EvilCharts' finite left-to-right reveals; underlying Recharts animations stay disabled for these renderers to avoid duplicate motion. Pie, radial, and radar use their underlying 650 ms entrances, and waterfall range bars use 600 ms. Reduced-motion preferences disable these introductions. Dashboard chart parents do not receive layout or entrance transforms; a memoized dashboard and stable source callback preserve chart instances while typing or opening source details. Tooltip values use authoritative dataset fields and their declared units. Radial domains use the backend's validated whole (`max=dataset.total`), rather than scaling the largest category to a full circle. Radar uses only backend-normalized comparable indices; values above 100 remain visible.

Waterfall is an explicit exception: EvilCharts has no waterfall component. The dynamic renderer uses Recharts range bars inside EvilCharts' `ChartContainer`, with backend-validated start/delta/end rows and the same tooltip, units, periods, and source controls. The existing sample report's custom profit bridge remains available. Sankey is intentionally absent because this dataset contains ledger amounts rather than measured stage-to-stage flows. Scatter, heatmap, and treemap are not registered. Model output never becomes arbitrary chart options, JSX, SQL, or executable code.
