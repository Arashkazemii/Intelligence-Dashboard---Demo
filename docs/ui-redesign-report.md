تصویر «قبل» فضای کاری، صفحهٔ خالی است؛ تصویر «بعد» پاسخ واقعی ثبت‌شدهٔ مدل را نشان می‌دهد. این دو تصویر از نظر محتوای تحلیل یک حالت یکسان نیستند. برای مقایسه با مرجع نیز [Landing در ابعاد مرجع](../artifacts/after-landing-reference-size.png) و [محیط کاری در ابعاد مرجع](../artifacts/after-workspace-reference-size.png) ثبت شده‌اند.

Landing زمینهٔ نزدیک مشکی، تیتر سمت راست، فضای خالی و ستون نور در سمت مقابل دارد. هستهٔ روشن، هاله، ذرات محدود و نورِ برخورد با لبهٔ بالای پیش‌نمایش با CSS ساخته شده‌اند. نارنجی روی نور، CTA و نقاط تأکید محدود است. پیش‌نمایش از API گزارش نمونه و مؤلفهٔ نمودار موجود پروژه استفاده می‌کند؛ برچسب «دادهٔ ساختگی» و توضیحِ غیرزنده‌بودن آن روشن است. «شروع» مستقیماً وارد `#question` می‌شود؛ گزارش نمونهٔ موجود از `#report` در دسترس است.

محیط کاری، ستون گفت‌وگوی راست و ناحیهٔ داشبورد مستقل دارد. دادهٔ KPI، نمودار، جدول، insight و ترتیب اجزا از پاسخ معتبر می‌آید. تعداد کارت‌ها ثابت فرض نشده است. عدد و واحدِ KPI جداگانه خوانده می‌شوند؛ تعریف و مقدار دقیق در «جزئیات شاخص» قرار دارند. سطرهای منبع همچنان از API دریافت و با جمع دقیق BigInt تطبیق داده می‌شوند. برای نمونه، مقدار دقیق درآمد فصل سوم در مرورگر `۱۳۵٬۰۰۰٬۰۰۰٬۰۰۰` تومان تأیید شد.

در تبلت ۸۳۴px، ستون چت باریک‌تر و نمودارها یک‌ستونه می‌شوند. زیر ۷۶۰px، چت و داشبورد به جریان عمودی تبدیل می‌شوند و پس از پاسخ، تمرکز دید به داشبورد منتقل می‌شود. در موبایل ۳۹۰px، کارت‌ها تک‌ستونه‌اند. جدول‌های عریض در ظرف خود اسکرول می‌شوند؛ خود صفحه overflow افقی ندارد.

فونت وزیرمتن و Motion موجود حفظ شدند. رنگ‌های درآمد، بهای کالا، هزینه و سود مستقل‌اند؛ همهٔ سری‌ها نارنجی نشده‌اند. کنترل‌های تزئینیِ مرجع، Export، صدا، اعلان و فیلتر بی‌عمل اضافه نشده‌اند. سؤال‌های هر نشست مستقل‌اند و این موضوع در ورودی ذکر شده است؛ مرور هشت پاسخ اخیر فقط در حافظهٔ همان فضای کاری انجام می‌شود.

## انتخاب حرکت و تعامل

مستندات رسمی [Motion React](https://motion.dev/docs/react)، [layout](https://motion.dev/docs/react-layout-animations)، [دسترس‌پذیری](https://motion.dev/docs/react-accessibility)، [EvilCharts](https://evilcharts.com/docs) و [Chart Config](https://evilcharts.com/docs/chart-config)، همراه با کد vendored فعلی پروژه بررسی شدند.

| بخش | گزینه‌های بررسی‌شده | انتخاب نهایی |
| --- | --- | --- |
| ورود Landing | فنری و جهشی؛ fade همراه جابه‌جایی کوتاه | ورود ۳۲۰ms با جابه‌جایی ۱۲px و تأخیر محدود |
| CTA | درخشش دائم؛ hover/tap کوتاه | hover به اندازهٔ ۲px و tap با scale برابر ۰٫۹۷ |
| جابه‌جایی صفحه | حرکت بزرگ یا shared layout؛ fade | fade برابر ۱۴۰ms، با مدیریت focus |
| پیام و KPI | ورود هم‌زمان سنگین؛ ورود کوتاه مستقل | پیام ۳۲۰ms و KPI برابر ۲۵۰ms |
| insight | تایپ تدریجی؛ وابستگی به scroll؛ fade محدود | fade برابر ۳۰۰ms با تأخیر حداکثر ۳۰۰ms؛ متن هیچ‌وقت پشت scroll پنهان نمی‌ماند |
| جزئیات | scale روی کل داشبورد؛ بازشدن ارتفاع | ارتفاع خود disclosure طی ۲۰۰ms؛ نمودارها remount نمی‌شوند |
| نمودار | انیمیشن هم‌زمان والد و نمودار؛ ترسیم داخلی | reveal داخلی EvilCharts برای خط/سطح/میله/ترکیبی؛ ورود ۶۵۰ms برای دایره‌ای/شعاعی/radar و ۶۰۰ms برای waterfall |
| پرتو | حلقهٔ canvas/WebGL؛ لایه‌های CSS | تغییر شدت هسته در ۸ ثانیه و حرکت ۱۲px ذرات در ۱۲ ثانیه |

سرور وضعیت مرحله‌ای stream نمی‌کند؛ UI درصد یا مرحلهٔ ساختگی نشان نمی‌دهد. وضعیت درخواست، آماده‌شدن پاسخ، خطا، retry، لغو و بارگذاری سطرهای منبع به رویداد واقعی وابسته‌اند. لغو، درخواست مرورگر را abort می‌کند؛ توقف پردازش داخلی سرویس مدل تضمین نمی‌شود.

`MotionConfig reducedMotion="user"`، hook نمودار و media query CSS اعمال شده‌اند. در حالت reduce، پرتو و ذرات متوقف می‌شوند، transform و layout غیرضروری حذف می‌شوند و نمودارها بدون ترسیم متحرک دیده می‌شوند. حلقهٔ دائمی JS، WebGL یا blur گسترده اضافه نشده است.

## نتیجهٔ بررسی‌ها

| بررسی | نتیجه |
| --- | --- |
| `tsc -b && vite build` در Docker | موفق؛ image نهایی web ساخته و اجرا شد |
| مجموعهٔ backend روی PostgreSQL موقت و جدا | ۹۲ passed؛ یک هشدار deprecation موجود در Starlette/httpx |
| «داشبورد بده» با مدل واقعی | پاسخ معتبر؛ KPI، نمودار و insight |
| «داشبورد حمل بده» با مدل واقعی | پاسخ معتبر؛ نمودار ترکیبی/خطی و drill-down |
| «نقاط قوت و ضعف را نشان بده» با مدل واقعی | پاسخ معتبر؛ چیدمان و تعداد اجزای متفاوت |
| «درآمد فصل سوم چقدر بود؟» با مدل واقعی | یک KPI، بدون نمودار یا insight اضافی |
| پاسخ‌های واقعی در ۱۴۴۰×۱۰۰۰، ۸۳۴×۱۱۱۲ و ۳۹۰×۸۴۴ | بدون overflow افقی، نمودار مفقود یا insight پنهان |
| ۱۲ renderer، دسکتاپ و موبایل | همه SVG و mark قابل مشاهده داشتند؛ بدون خطای JavaScript |
| سطر منبع حمل | ۳ سطر واقعی؛ جمع دقیق با API تطبیق داشت |
| گزارش نمونهٔ قبلی | ناوبری بخش‌ها، دریافت سطر درآمد و تطبیق جمع حفظ شدند |
| خطا/retry، دادهٔ ناکافی، لغو | موفق؛ fault injection فقط در مرورگر آزمون |
| حرکت پرتو | opacity در نمونه‌برداری از ۰٫۶۷۴ به ۰٫۸۲۰ تغییر کرد |
| reduced-motion | animation و transform پرتو هر دو `none` |
| حرکت واقعی نمودار | scaleX ماسک طی ۳۰۰ms از حدود ۰٫۴۸ به ۰٫۹۶ تغییر کرد |
| حفظ نمودار | تایپ و بازشدن داده، هویت DOM نمودار را حفظ کردند |
| hover/focus | جابه‌جایی CTA برابر ۲px؛ focus-visible با outline تأیید شد |
| جلسهٔ تازهٔ Chrome | صفر خطا و صفر هشدار کنسول |
| Docker Compose دمو | هر سه سرویس سالم؛ محیط تست موقت جمع شد |

چهار سؤال در مرورگر واقعاً به مدل ارسال شدند. برای عکس‌برداری تکرارپذیر پس از اصلاحات ظاهری، همان پاسخ‌های واقعی در sessionStorage آزمون نگه داشته و در مرورگر بازپخش شدند؛ این بازپخش فراخوانی تازهٔ مدل نیست. مسیر واقعی محصول از fixture یا sessionStorage آزمون نمی‌خواند. fixture دوازده نمودار نیز فقط در تست renderer استفاده شد و از دادهٔ واقعی پایگاه نمایشی ساخته شده است.

اسکریپت‌های بررسی در `scripts/check_redesign_*_browser.js` ثبت شده‌اند. تست زنده روی یک جلسهٔ نام‌دار Chrome در چهار اجرا انجام می‌شود؛ تست visual به پاسخ‌های ثبت‌شدهٔ همان جلسه وابسته است. تست registry/states به `.local/chart-fixture.json` تولیدشده توسط `scripts/export_chart_fixture.py` و سرور محلی فقط‌خواندنی روی پورت ۸۷۶۵ نیاز دارد.

## محدودیت‌های باقی‌مانده

- مدل خارجی قطعی نیست. یک درخواست تکراری با `502 / invalid_reference` توسط اعتبارسنجی backend رد شد؛ تلاش بعدی پاسخ معتبر داد. UI خطا را نشان می‌دهد و امکان retry دارد. منطق اعتبارسنجی برای پوشاندن این خطا تضعیف نشد.
- بررسی مرورگر با Chrome سیستم انجام شد؛ Safari/Firefox و سخت‌افزار فیزیکی موبایل آزمایش نشده‌اند. مصرف GPU/CPU روی لپ‌تاپ کاربر benchmark نشده است.
- سابقهٔ پرسش‌ها با خروج از محیط کاری یا reload پاک می‌شود؛ ذخیرهٔ دائمی یا گفت‌وگوی چندمرحله‌ای به backend اضافه نشده است.
- Graphify محلی برای هشت فایل مرتبط تازه شد؛ ۸۷۹ node و ۲۰۰۸ edge، بدون فراخوانی semantic API. diagnostic استخراج جزئی، ۷۳ endpoint بیرونی/حل‌نشده و ۱۲ هم‌پوشانی رابطه گزارش کرد؛ `main.tsx` نماد مستقلی تولید نکرد. گراف برای مکان‌یابی استفاده شد و تصمیم‌ها با خود source بررسی شدند.
